# AnyVector 0.4.0

AnyVector 0.4.0 works more like CorelDRAW under your fingers. The keyboard shortcuts match CorelDRAW 2026, text is
edited right on the page, copy and paste work, and there's a Light theme and 13 more interface languages.

## Keyboard shortcuts as in CorelDRAW

- **The same keys as CorelDRAW 2026.** Every shortcut was checked against CorelDRAW 2026's own shortcut table. They
  are the same in every interface language, as in CorelDRAW. New keys include:
  - J for the Painterly Brush and S for LiveSketch
  - P to center the selection on the page
  - Shift+L, E, R, T, B, C, P and A to distribute objects
  - Ctrl+F9 (Contour), Ctrl+F7 (Envelope), Alt+F3 (Lens), and Alt+F8 to Alt+F10 for the Transform docker's pages
  - Ctrl+Shift+V (Paste in View) and Ctrl+Shift+J (Join Curves)
- **Second keys.** Ctrl+Insert copies, Shift+Insert pastes, Shift+Delete cuts, Backspace deletes, Ctrl+= zooms in, and
  Ctrl+Home and Ctrl+End bring objects to the front or the back.
- **Keys while you edit text.** Ctrl+B, Ctrl+I and Ctrl+U set bold, italic and underline, Ctrl+L, Ctrl+E, Ctrl+R and
  Ctrl+J align the text, and keys that mean something else elsewhere no longer run while you type.
- **Keys for nodes.** With nodes selected in the Shape tool, C, S and L make them cusp, smooth or symmetrical, and
  turn lines into curves.
- **Align centers.** C and E align centers as the menus say (they were swapped).
- **Fixed.** Ctrl+Shift+S saves as, Ctrl+Shift+Z redoes and Ctrl+Shift+D opens Step and Repeat (they ran Save, Undo
  and Duplicate). Shift+arrow moves objects by the super nudge.

## Drawing

- **Cusp nodes with the Pen and Bézier tools.** Hold C while you drag a node's handles to make it a cusp, so the curve
  can change direction. Ctrl keeps the handle or the segment at the constrain angle, and Alt moves the node while you
  place it.
- **Shape tool.** Ctrl keeps a node or a handle you drag on a straight line.
- **Break Apart on the property bar.** The Break Apart button on the curve property bar works for a curve made of
  several parts (it was always off).

## Text

- **Double-click to edit text.** Double-clicking text with the Pick tool edits it right on the page, with the cursor
  where you clicked. The Edit Text dialog is still on Ctrl+Shift+T.

## Copy and paste

- **Ctrl+C and Ctrl+V.** Copying and pasting objects with the keyboard works (only the menus did before).
- **Pictures from the web.** A picture copied in a browser pastes as a bitmap, at the size it has on screen. It used
  to paste its web address as text, or nothing.

## Guidelines

- **Delete a guideline.** Click a guideline with the Pick tool to select it (it turns red), then press Delete. Undo
  brings it back.

## Interface

- **Light theme.** Tools ▸ Options ▸ Appearance ▸ Theme switches between the dark and the light look.
- **13 more languages**, the ones CorelDRAW 2026 has: Chinese (Simplified and Traditional), Czech, Dutch, French,
  German, Italian, Japanese, Polish, Russian, Spanish, Swedish and Turkish. The installer and the first start offer
  all 15.
