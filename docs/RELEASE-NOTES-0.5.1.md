# AnyVector 0.5.1

AnyVector 0.5.1 fixes five bugs reported after 0.5.0.

## Fixes

- **Move the rotation centre.** Click a selected object again to get the rotate handles, then drag the centre marker
  to where it should turn. It snaps like other points, and rotating turns the object around it.
- **Move dialogs.** Dialogs can be dragged by their title bar, and they stay on the screen. Quick AI Generate can
  be moved too.
- **Round rectangle corners by dragging.** With the Shape tool, drag a rectangle's corner node along a side to round
  the corners. The rounding follows the pointer, and a rounded corner shows its nodes where the curve meets the
  sides, as in CorelDRAW.
- **Bright palette colors.** Palette swatches and color wells now show colors the same way the page does. With Color
  Proofing or color management off, they are no longer dull.
- **Mouse wheel zoom like CorelDRAW.** One wheel notch now zooms by the full amount set in Options, so it takes as
  many notches as in CorelDRAW.
