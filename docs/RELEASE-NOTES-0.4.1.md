# AnyVector 0.4.1

AnyVector 0.4.1 lets you send a file with a bug report or an idea.

## Bug reports and ideas

- **Attach a file.** Help ▸ Report a Bug and Help ▸ Submit Ideas and Feedback have an Attach File button. The file
  goes to the issue on GitHub with your report, and a picture shows right in it. You still don't need a GitHub
  account.
- **The same files GitHub takes.** Pictures and videos up to 10 MB, and documents, logs, text and .zip files up to
  25 MB. Put a drawing (.cdr, .vct) in a .zip file first. The dialog tells you when a file can't be sent, and why.
- **When the report opens in your browser instead,** a folder opens on your file so you can drag it into GitHub's
  page.
